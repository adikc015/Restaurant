🍽️ Restaurant Website
A fully responsive and modern restaurant website built using HTML, CSS, and JavaScript.
This project is designed as a simple frontend static website showcasing a restaurant's online presence.

🚀 Live Demo
👉 [View Live Website](https://adikc015.github.io/Restaurant/)

📂 Project Structure
Restaurant/
├── index.html
├── style.css
├── script.js
├── images/
│   └── (all image assets)


- `index.html` – Main webpage
- `style.css` – Stylesheet for design and responsiveness
- `script.js` – JavaScript file for basic interactions
- `images/` – Folder containing all images used

---

## ✨ Features

- Modern and clean design
- Fully responsive across devices (desktop, tablet, mobile)
- Smooth navigation bar
- Sections: Home, About, Menu, Contact
- Basic JavaScript effects
- Fast loading and user-friendly

---

## 🛠️ Built With

- **HTML5** – Structure
- **CSS3** – Styling and Layout
- **JavaScript** – Interactivity
